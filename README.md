# Rukn (ركن) — Bilingual Classified-Ads Marketplace
Laravel 13 · PHP 8.3+ · Blade · Tailwind · SQLite

Student: Omar Abdulelah Omar Alsabbah — ID 44710471

## Run
1. composer install
2. npm install
3. copy .env.example .env
4. php artisan key:generate
5. php artisan migrate --seed   (answer "yes" if asked to create database.sqlite)
6. npm run build
7. php artisan serve  ->  http://localhost:8000
